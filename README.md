# Умная карта ВТБ

**Персонализированный гео-сервис для поиска выгодных предложений партнёров банка**

[![Streamlit App]][https://smartmapvtb.streamlit.app/]

## О проекте

«Умная карта» — это двусторонняя платформа, которая через интерактивную карту выгодных предложений с кэшбеком и акциями связывает клиентов и бизнес:

**Для клиентов:** находят на карте персонализированные предложения партнеров, экономят на повседневных покупках
**Для бизнеса:** привлекают новых клиентов, управляют акциями и видят реальную аналитику эффективности

### Core-фичи

"Умная карта ВТБ" — платформа, которая позволяет бизнесу привлекать новых клиентов через персонализированные акции с показателями окупаемости инвестиций (ROI), а клиентам — видеть на карте выгодные предложения, релевантные именно для них, и активировать одним касанием их для покупок в удобном месте, экономя на повседневных покупках без поиска купонов и сравнения цен. Также для клиентов доступен инструмент аналитики трат на карте, визуализирующий в виде точек крупные места скопления трат.

**Умная карта** Показ трат клиента и выгодных предложений партнеров с возможностью активировать его
**Механизм персонализации** Показ только релевантных предложений с отметками "Любимое место" и «Что-то новенькое» (похожая категория трат)
**Инструмент аналитики для бизнеса** Показ статистики доходности с предложения: активации, новые клиенты и выручка для каждого оффера

### Установка

1. **Клонируйте репозиторий**
git clone https://github.com/mtitenko5/smart_map_vtb.git
cd smart_map_vtb

2. **Установите зависимости**
pip install -r requirements.txt

3. **Запустите приложение**
streamlit run app.py

Откройте браузер — приложение будет доступно по адресу http://localhost:8501

### Основные экраны
**Для клиента:**

Выгода рядом — карта с выгодными предложениями и их активация

Мои траты — карта трат и аналитика по категориям

Уведомления — персональные рекомендации и напоминания

**Для бизнеса:**

Дашборд — KPI (новые клиенты, выручка, выгода от использования нашего сервиса)

Предложения — создание/редактирование акций для клиента и аналитика их эффективности

Отзывы — обратная связь от клиентов

Уведомления — сообщения от сервиса
