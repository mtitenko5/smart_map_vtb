# Умная карта ВТБ

Персонализированный гео-сервис для поиска выгодных предложений партнёров банка.

## О проекте

**«Умная карта ВТБ»** — это концепт двустороннего сервиса, который объединяет клиентов банка и бизнес-партнёров через карту персонализированных предложений.

**Для клиента:**
- поиск ближайших выгодных предложений на карте;
- персональные рекомендации на основе покупательского поведения;
- просмотр истории и географии трат;
- активация предложений в один клик.

**Для бизнеса:**
- размещение и управление акциями;
- отслеживание отклика по предложениям;
- просмотр ключевой аналитики по офферам;
- работа с отзывами и уведомлениями.

## Ключевые возможности

### Для клиента
- **Карта предложений** — отображение выгодных предложений партнёров на карте.
- **Персонализация** — рекомендации с пояснением, почему предложение может быть интересно клиенту.
- **Активация предложений** — получение промокода или активация акции прямо в интерфейсе.
- **Карта трат** — визуализация мест, где пользователь чаще всего совершает покупки.

### Для бизнеса
- **Бизнес-дашборд** — выручка, активации, новые клиенты, динамика по предложениям.
- **Управление офферами** — создание, редактирование и анализ предложений.
- **Отзывы** — просмотр обратной связи от клиентов.
- **Уведомления** — сообщения о статусе предложений и достижении целей.

## Требования

- Python 3.9+
- `pip`

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/mtitenko5/smart_map_vtb.git
cd smart_map_vtb
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск приложения

```bash
streamlit run app.py
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8501
```

## Демо-доступ

| Роль | Логин | Что доступно |
|---|---|---|
| Клиент | `bubliki` | Карта предложений, траты, активация скидок, уведомления |
| Бизнес | `coffee_admin` | Дашборд, управление предложениями, отзывы, уведомления |

## Основные экраны

### Клиентский интерфейс
- **Выгода рядом** — карта с актуальными предложениями и возможностью активации.
- **Мои траты** — карта трат, категории расходов и история операций.
- **Уведомления** — персональные рекомендации и напоминания.

### Интерфейс партнёра
- **Дашборд** — основные KPI и краткая аналитика.
- **Предложения** — создание, редактирование и просмотр эффективности офферов.
- **Отзывы** — обратная связь от клиентов.
- **Уведомления** — системные сообщения и напоминания.
